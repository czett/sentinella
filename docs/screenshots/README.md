# Dashboard Screenshots

Drop captured screenshots from a live CCU3 / RaspberryMatic instance (or local `?demo=1` preview) into this directory using the filenames below, then uncomment the image block in `README.md` and `README.de.md`.

| Filename | Description | Recommended Viewport |
|---|---|---|
| `desktop-light.png` | Main dashboard in light mode showing the Hero Tile, thresholds rail, history chart, and `05 Extensions` grid | `1280×800` |
| `settings-drawer.png` | Open Settings Drawer showing Hero source, battery thresholds, CallMeBot onboarding, inverter, and plugin toggles | `1280×800` |
| `mobile-view.png` | Mobile responsive stacked view with pull-to-refresh layout | `390×844` |
